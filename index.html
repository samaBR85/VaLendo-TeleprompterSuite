Rewrite the script
while the show is on the air.

A teleprompter for Windows and macOS where the operator edits the text live, watching the editor and an exact replica of the presenter's screen side by side.

The reading position is an anchor in the text, not a pixel on the screen.

Why it exists

Other teleprompters make you stop to edit

They store the scroll position in pixels. Any change to the text, the typeface or the margin reflows the layout, and pixel 4,200 is suddenly a different sentence — the text jumps in the presenter's face. That is not a missing feature; it is the storage model.

Valendo stores the position as a semantic anchor: { blockId, wordOffset }. Block seven, word thirty-four. After any reflow the pixel is recomputed from it. Insert paragraphs above the reading point, raise the type size, change the margin — the word being read does not move.

A clock, not messages

The main process keeps three numbers: pace, where the reading started, and when. Each window solves the same equation. Nothing is sent per frame, so nothing can drift.

One component, two screens

The same code draws the broadcast and the operator's preview. The preview runs at the output's real viewport and only gets a scale. The replica is exact by construction.

Lines composed by words

A word rule decides where a line breaks, not the browser. Changing the type size changes the height of a line and nothing else.

Cards

Over the script, or instead of it

Images, video and messages go to the presenter's screen with one click or a number key. Each card either replaces the script or rides over it — which is how a lower third and a caption share one screen.

Legibility over a card is a three-way choice: a dark band, a shadow behind each letter, or nothing at all.

Video plays the file as it arrived whenever the browser can handle it. When it cannot, ffmpeg first tries to change only the container — seconds, no pixel touched — and re-encodes only when the content genuinely will not fit an mp4.

Three ways to work

Split, Focus, Desk

Split is the picture at the top of this page — the editor and the presenter's screen together, which is how a show is operated.

Focus hides everything except the script and the transport, for the last rehearsal before air.

Desk turns the script into a rundown: every block with its word count, duration and on-air status, and a timeline across the top.

Output

The presenter's screen

Any connected monitor, identified on screen before you send a show to it. Mirror on either axis for teleprompter glass, 90° rotation for a screen mounted sideways, blackout and freeze on a key.

If that monitor is unplugged mid-show, Valendo closes the output rather than leaving a window at coordinates that no longer exist.

Local network

Anyone on the wi-fi can follow along

One switch publishes the reading to a page on the local network. A phone points its camera at the QR code and follows the same scroll, with the same cards, exactly as the presenter sees it. Nothing to install.

Video going out can be throttled to five weight profiles, because a phone on wi-fi is not a monitor on a cable. The presenter's screen always gets the original.

Privacy

It opens without opening your work

Valendo never restores the last script by itself. Opening a teleprompter in a studio that is not yours, or with the machine already mirrored to a wall, would otherwise put the previous show in front of whoever is in the room — and a script is a client's material.

The screen starts blank. Pick up where I left off is a deliberate click, and the list of recent projects can be emptied for good.

Everything else

What is in the box

Reading

Chapters, markers, reading line, go-to-cursor, up to ten tabs, infinite undo kept across sessions.

Transport

Play/pause on Space, a words-per-minute ruler, nudge, loop with a delay, auto-pause at the end.

Pacing

Formula, stopwatch or free run. Elapsed, remaining and a target duration that adjusts the pace to fit.

Appearance

Family, size, weight, spacing, ALL CAPS, margin, position, words per line, colour presets, invert.

Files

Import and export txt, md, docx and pdf. Projects in a single .valendo file. Autosave underneath.

Console

Command palette, every key remappable, interface scale, transport at the top or in the footer.

Six languages

English, Portuguese (Brazil), Spanish, German, French, Italian — picked from the system on first run.

Free software

GPL-3.0-or-later. Use it, study it, change it, sell services around it. It cannot be closed.

Install

Two ways in

Windows installer

Download the latest Valendo-setup.exe from Releases. It installs per user, so it does not ask for an administrator password.

From source

git clone https://github.com/samaBR85/Valendo-TeleprompterSuite.git
cd Valendo-TeleprompterSuite
npm install
npm run dev

The rest — the other commands, the project layout, the tests — is in Building from Source.
